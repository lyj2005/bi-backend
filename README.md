# 项目介绍

传统项目（数据分析平台） ：由专业的数据分析师完成分析，
我的项目：用户只需输入想要分析的目标，并上传原始数据，系统将利用AI自动生成可视化图表和学习的分析结论。

# 业务流程
①客户端输入分析诉求和原始数据，向业务后端发送请求。②业务后端利用 AI 服务处理客户端数据，保持到数据库，并生成图表。③处理后的数据由业务后端发送给 AI 服务，AI 服务生成结果并返回给后端，最终将结果返回给客户端展示。
