# 项目介绍

传统项目（数据分析平台） ：由专业的数据分析师完成分析，
我的项目：用户只需输入想要分析的目标，并上传原始数据，系统将利用AI自动生成可视化图表和学习的分析结论。

### 主流框架 & 特性

- Spring Boot
- Spring MVC
- MyBatis + MyBatis Plus 数据访问（开启分页）
- Spring AOP 切面编程

### 数据存储

- MySQL 数据库
- Redis 内存数据库

### 工具类

- Easy Excel 表格处理
- Hutool 工具库
- Apache Commons Lang3 工具类
- Lombok 注解

### 业务特性

- Spring Session Redis 分布式登录
- 全局异常处理器
- 自定义错误码
- 封装通用响应类
- Swagger + Knife4j 接口文档
- 自定义权限注解 + 全局校验
- 全局跨域处理
- 长整数丢失精度解决
- 多环境配置


## 业务功能

- 用户登录、注册、注销、更新、检索、权限管理
- 图表AI分析、可视化展示

### 单元测试

- JUnit5 单元测试
- 示例单元测试类

### 架构设计

- 合理分层
